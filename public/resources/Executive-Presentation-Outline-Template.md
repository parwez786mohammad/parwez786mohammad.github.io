# Executive Presentation Outline Template

A structure for project/status presentations to leadership.

1. **Title Slide** — Project name, date, presenter
2. **Executive Summary** — 3 bullets: status, key win, key ask
3. **Objectives Recap** — Why this project exists
4. **Progress vs Plan** — Milestones, RAG status
5. **Key Metrics / KPIs** — Visual, not tables where possible
6. **Risks & Issues** — Top 3 only, with mitigation
7. **Decisions Needed** — Be explicit about the ask
8. **Next Steps** — Owner + date for each
9. **Appendix** — Detailed data for those who want to dig in
